# سخن | Sokhan

**سخن** ابزار متن‌باز و محلی‌محور برای تبدیل محتوای انگلیسی به فارسی طبیعی است. هدف پروژه فقط ترجمه کلمه‌به‌کلمه نیست؛ بلکه حفظ معنا، نیت گوینده، لحن، زمان‌بندی و در مراحل بعدی ویژگی‌های صوتی گفتار است.

> وضعیت فعلی: زیرساخت اولیه، ابزارهای قطعی متن و زیرنویس، قراردادهای نوع‌دار، استخراج متن PDF و اتصال ترجمه به یک سرور مدل محلی پیاده‌سازی شده‌اند. دوبله، تشخیص گوینده، تحلیل احساس و کلون‌کردن صدا هنوز در مرحله توسعه‌اند و نباید قابلیت آماده محصول تلقی شوند.

## استفاده

~~~bash
sokhan normalize-fa input.txt
sokhan extract-pdf document.pdf
sokhan srt-check captions.srt --max-duration-ms 120000\nsokhan vtt-check captions.vtt\nsokhan extract-audio input.mp4 audio.wav
~~~

### استخراج صوت و زیرنویس فارسی

برای ترجمه زیرنویس موجود نیز فرمان‌های translate-srt و translate-vtt در دسترس‌اند و فایل خروجی را بدون overwrite ایجاد می‌کنند:

~~~bash
sokhan translate-srt captions.en.srt captions.fa.srt
sokhan translate-vtt captions.en.vtt captions.fa.vtt
~~~

برای استخراج صوت، FFmpeg باید روی سیستم نصب باشد:

~~~bash
sokhan extract-audio input.mp4 audio.wav
~~~

برای ASR و تولید زیرنویس فارسی، افزونه صوتی را نصب و یک مدل ترجمه محلی را اجرا کنید:

~~~bash
python -m pip install -e ".[audio]"
sokhan audio-to-srt audio.wav output.fa.srt --asr-model small.en --device cpu
~~~

مدل ASR در نخستین اجرا ممکن است از منبع مدل دریافت و در cache محلی نگهداری شود. این فرمان فقط فایل صوتی را پردازش و زیرنویس SRT تولید می‌کند؛ هیچ ویدئویی بازسازی یا دوبله نمی‌شود.

### ترجمه با مدل محلی

سخن هیچ سرویس ابری را به‌صورت پنهانی فراخوانی نمی‌کند. یک سرور محلی سازگار با OpenAI Chat Completions (برای نمونه llama.cpp یا درگاه محلی مشابه) اجرا کنید:

~~~bash
export SOKHAN_LLM_BASE_URL=http://127.0.0.1:1234
export SOKHAN_LLM_MODEL=your-local-model
sokhan translate input.txt --register conversational
~~~

حالت پیش‌فرض فقط میزبان‌های محلی را می‌پذیرد. فعال‌کردن endpoint خارجی نیازمند تنظیم صریح SOKHAN_ALLOW_EXTERNAL_PROVIDER=true است؛ این گزینه را فقط برای سرویس مورد اعتماد و با آگاهی از ارسال داده استفاده کنید.

## معماری هدف

- **متن و اسناد:** استخراج، پاک‌سازی، ترجمه، بازبینی و خروجی PDF راست‌چین.
- **صوت:** استخراج صوت، ASR، تفکیک گوینده، تحلیل لحن و احساس، ترجمه و TTS.
- **زیرنویس:** حفظ شناسه و زمان‌بندی، ترجمه قطعه‌ای و تنظیم طول نمایش.
- **صدا:** استفاده از صدای جایگزین یا انتقال هویت صدا فقط با رضایت و مجوز روشن صاحب صدا.
- **ویدئو:** در نسخه نخست فقط استخراج صوت و کار با زیرنویس؛ تولید ویدئوی دوبله‌شده خارج از دامنه است.

## انتخاب مدل

مدل‌ها با معیارهای کیفیت فارسی، طبیعی‌بودن، وضوح، حفظ معنا، شباهت گوینده، سرعت CPU/GPU، حافظه و مجوز دقیق ارزیابی می‌شوند. نام یک دیتاست یا پشتیبانی ادعایی از چندصد زبان، اثبات کیفیت فارسی نیست. فهرست نامزدها و وضعیت بررسی مجوزها در docs/MODEL_REGISTRY.md نگهداری می‌شود.

## توسعه و بهبود مستمر

- CI روی Python 3.11 تا 3.13 اجرا می‌شود.
- بررسی کیفیت هفتگی فقط از داده‌های مصنوعی و تست‌های محلی استفاده می‌کند.
- ایجنت‌های پژوهش و نگه‌داری می‌توانند گزارش، Issue و PR آماده کنند؛ ادغام خودکار یا نوشتن مستقیم روی main مجاز نیست.
- وزن مدل‌ها در CI دانلود نمی‌شوند و فایل صوتی کاربران به artifact ارسال نمی‌شود.
